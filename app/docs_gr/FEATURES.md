## 4. 3D Φωτογραμμετρία

### Κύρια Λειτουργία
Το επίκεντρο του AncientVision - πραγματική 3D ανακατασκευή Structure from Motion.

### Σύστημα Λήψης

#### 16 Βελτιστοποιημένες Γωνίες
| Δακτύλιος | Θέσεις | Περιγραφή |
|-----------|--------|-----------|
| Δακτύλιος 1 | 8 | Ύψος ματιών, κάθε 45° |
| Δακτύλιος 2 | 4 | 45° ανύψωση, κάθε 90° |
| Κορυφή | 2 | 80° και 70° από πάνω |
| Λεπτομέρεια | 2 | Κοντινές λήψεις |

#### Τρόποι Λήψης
- **Λειτουργία Φωτογραφίας** - Μεμονωμένες λήψεις με καθοδήγηση
- **Λειτουργία Βίντεο** - Συνεχής εγγραφή με εξαγωγή καρέ
- **Λειτουργία Tutorial** - Βήμα-βήμα για αρχάριους

### Καθοδήγηση AR-Like
Ανατροφοδότηση αισθητήρων σε πραγματικό χρόνο κατά τη λήψη:
- Δείκτες κλίσης συσκευής (άξονες X/Y)
- Εμφάνιση κατεύθυνσης πυξίδας
- Προειδοποίηση ταχύτητας περιστροφής
- Οπτικοί δείκτες γωνίας

### Ανάλυση Ποιότητας
Κάθε φωτογραφία αναλύεται για:
- **Ευκρίνεια** - Διακύμανση Laplacian (στόχος: >500)
- **Έκθεση** - Ιστόγραμμα φωτεινότητας
- **Θόλωμα** - Ανίχνευση θολώματος κίνησης
- **Θόρυβος** - Εκτίμηση θορύβου αισθητήρα

### 3D Ανακατασκευή

#### Βήματα Διαδικασίας
1. Φόρτωση & επικύρωση εικόνων
2. Εξαγωγή χαρακτηριστικών Harris corner
3. Αντιστοίχιση χαρακτηριστικών μεταξύ εικόνων
4. Εκτίμηση Essential Matrix (αλγόριθμος 8 σημείων)
5. Απόρριψη ακραίων τιμών RANSAC
6. Ανάκτηση θέσεων κάμερας
7. Τριγωνοποίηση 3D σημείων
8. Βελτιστοποίηση προσαρμογής δέσμης
9. Δημιουργία point cloud
10. Εξαγωγή αποτελεσμάτων

#### Αλγόριθμοι που Χρησιμοποιούνται
| Αλγόριθμος | Σκοπός |
|------------|--------|
| Harris Corner | Ανίχνευση χαρακτηριστικών |
| Cross-Correlation | Αντιστοίχιση χαρακτηριστικών |
| Αλγόριθμος 8 Σημείων | Essential matrix |
| RANSAC | Απόρριψη ακραίων τιμών |
| Τριγωνοποίηση | Υπολογισμός 3D σημείων |
| Bundle Adjustment | Βελτίωση |

#### Μετρήσεις Επιτυχίας
- **Σφάλμα Επαναπροβολής** - Στόχος: <2.0 pixels
- **Κάλυψη** - Στόχος: >60%
- **Αριθμός Σημείων** - Τυπικό: 500-5000 σημεία
- **Ποσοστό Επιτυχίας** - 85-95% με σωστή λήψη

### Μέθοδοι Επεξεργασίας

#### Cloud Processing (Συνιστάται)
Χρησιμοποιεί **OpenScan Cloud API** - εντελώς ΔΩΡΕΑΝ υπηρεσία.

| Πτυχή | Λεπτομέρειες |
|-------|-------------|
| Ποιότητα | Επαγγελματικό πυκνό mesh με υφές |
| Χρόνος | 5-15 λεπτά |
| Απαιτεί | Σύνδεση internet |
| Έξοδος | GLB/OBJ με υφές |
| Καλύτερο για | Τελική τεκμηρίωση |

#### Επεξεργασία στη Συσκευή
Γρήγορη προεπισκόπηση χρησιμοποιώντας αλγόριθμους SfM στη συσκευή.

| Πτυχή | Λεπτομέρειες |
|-------|-------------|
| Ποιότητα | Αραιό point cloud |
| Χρόνος | 1-3 λεπτά |
| Απαιτεί | Τίποτα (λειτουργεί εκτός σύνδεσης) |
| Έξοδος | PLY point cloud |
| Καλύτερο για | Γρήγορη προεπισκόπηση, επαλήθευση πεδίου |

## 6. Παρακολούθηση Ασφάλειας v4.0

### Ενσωμάτωση Υλικού
Συνδέεται με μικροελεγκτή M5StickC Plus 2 μέσω Bluetooth Low Energy.

### Προηγμένη Σεισμική Ανάλυση (ΝΕΟ σε v4.0)

#### Arias Intensity
Μετρική σωρευτικής σεισμικής ενέργειας (π/2g·∫a²dt):
- Αυτόματη επαναφορά κάθε 60 δευτερόλεπτα
- Ποσοτικοποιεί τη συνολική σεισμική ενέργεια που παραδίδεται στη δομή
- Χρησιμοποιείται σε σεισμικούς κώδικες κτιρίων παγκοσμίως

#### CAV (Cumulative Absolute Velocity)
- Κατώφλι EPRI: 0.16 g·s για δομική ζημιά
- Βιομηχανικό πρότυπο για σεισμική ασφάλεια πυρηνικών εγκαταστάσεων
- Επίπεδα προειδοποίησης με χρωματική κωδικοποίηση στη διεπαφή

#### 3-Επίπεδο Haar DWT (Discrete Wavelet Transform)
Αποσύνθεση ζωνών συχνοτήτων στη συσκευή:
- D1: 50-100 Hz (μηχανήματα υψηλής συχνότητας)
- D2: 25-50 Hz (δομική μεσαίας συχνότητας)
- D3: 12-25 Hz (σεισμική χαμηλής συχνότητας)
- Οπτικοποίηση με χρωματιστές μπάρες στην εφαρμογή

#### Θερμοκρασία IMU
- Ανάγνωση θερμοκρασίας chip MPU6886
- Θερμική αντιστάθμιση μεροληψίας: 0.0005g/°C εφαρμόζεται στην επιτάχυνση
- Αποτρέπει ψευδείς συναγερμούς από θερμική παρέκκλιση

#### Αναδρομικό STA/LTA
- Υλοποίηση βασισμένη σε EMA εξοικονομεί 8KB RAM σε σχέση με v3.0
- Τυπικός αλγόριθμος ενεργοποίησης σεισμολογίας
- Λόγος > 4.0 δείχνει σεισμικό συμβάν

### Αισθητήρες που Παρακολουθούνται

#### Δόνηση (IMU)
| Επίπεδο | Εύρος | Σημασία |
|---------|-------|---------|
| Ασφαλές | <0.3g | Κανονικές συνθήκες |
| Προειδοποίηση | 0.3-0.8g | Ανιχνεύθηκε δόνηση εδάφους |
| Κρίσιμο | >0.8g | Κίνδυνος σεισμού/κατάρρευσης |

#### Υγρασία Εδάφους
| Επίπεδο | Εύρος | Σημασία |
|---------|-------|---------|
| Ασφαλές | 30-60% | Βέλτιστες συνθήκες |
| Ξηρό | <30% | Κίνδυνος ρωγμών εδάφους |
| Υγρό | >60% | Προειδοποίηση κορεσμού |
| Κρίσιμο | >80% | Κίνδυνος κατάρρευσης |

### Χαρακτηριστικά Οθόνης v4.0
- **Ζωντανές Τιμές** - Μετρήσεις αισθητήρων σε πραγματικό χρόνο
- **Δείκτες Κατάστασης** - Επίπεδα ασφαλείας με χρωματική κωδικοποίηση
- **Γράφημα Ιστορικού** - Τάση δόνησης 1 ώρας
- **Χρονολόγιο Ειδοποιήσεων** - Χρονολογικό αρχείο ειδοποιήσεων
- **ΝΕΟ: Σειρά Σεισμικών Μετρήσεων** - Arias Intensity, CAV (με κατώφλια EPRI), Θερμοκρασία
- **ΝΕΟ: Οπτικοποίηση DWT** - 3 μπάρες ζωνών συχνοτήτων (D1/D2/D3) με χρώματα πλάτους
- **Δυναμική Απόδοση** - Χαρακτηριστικά v4.0 εμφανίζονται μόνο με firmware v4.0

### Σύστημα Ειδοποιήσεων
- **Ειδοποιήσεις πλήρους οθόνης** σε ΟΛΕΣ τις καρτέλες (όχι μόνο στην Ασφάλεια)
- **Push notifications** ανεξάρτητα από ποια οθόνη βρίσκεστε
- **Απτική ανάδραση** (δόνηση τηλεφώνου) σε ειδοποιήσεις
- **Φωνητικές ειδοποιήσεις** μέσω text-to-speech
- **Ήχος συναγερμού** σε κρίσιμες ειδοποιήσεις
- **Καθολικό κουμπί σίγασης** στη γραμμή πλοήγησης ελέγχει όλους τους ήχους σε όλη την εφαρμογή
- Καταγραφή Firebase για αρχεία

### Διαχείριση Σύνδεσης BLE
- Η σύνδεση Bluetooth παραμένει ενεργή ακόμα και όταν αλλάζετε καρτέλες
- Αυτόματη επανασύνδεση σε απώλεια σήματος
- Διαπραγμάτευση MTU για αποφυγή αποκοπής δεδομένων JSON

## 11. Υποστήριξη Εκτός Σύνδεσης

### Σύστημα Αυτόματης Αποθήκευσης
- Πρόχειρα φόρμας αποθηκεύονται κάθε 2 δευτερόλεπτα
- Ενεργοποιείται σε κάθε αλλαγή κειμένου
- Επιβιώνει crashes εφαρμογής

### Ανάκτηση Πρόχειρων
- Αυτόματη προτροπή στην εκκίνηση εφαρμογής
- Επιλογές "Συνέχεια" ή "Απόρριψη"

### Ουρά Εκτός Σύνδεσης
- Ευρήματα αποθηκεύονται τοπικά όταν είστε εκτός σύνδεσης
- Αυτόματος συγχρονισμός όταν συνδεθείτε
- Οπτική ένδειξη εκκρεμών μεταφορτώσεων

### Τοπική Cache
- Πρόσφατα ευρήματα αποθηκεύονται
- Περιήγηση χωρίς internet
- Εικόνες αποθηκευμένες τοπικά

### Χαρακτηριστικά Συγχρονισμού
- Χειροκίνητη ενεργοποίηση "Συγχρονισμός"
- Συγχρονισμός στο παρασκήνιο όταν είστε online
- Επίλυση συγκρούσεων (κερδίζει ο server)

## 13. Γρήγορη Λήψη

Απλοποιημένη τεκμηρίωση μονής φωτογραφίας για ταχεία καταγραφή πεδίου.

### Σκοπός
Η γρήγορη λήψη παρέχει μια απλοποιημένη ροή εργασίας για την τεκμηρίωση ευρημάτων χωρίς πλήρη συμπλήρωση φόρμας. Ιδανική για:
- Αρχική τεκμηρίωση ανακάλυψης
- Ταχείες έρευνες τοποθεσίας
- Φωτογράφιση in-situ πριν την ανασκαφή
- Καταστάσεις χρονικής πίεσης

### Ροή Εργασίας Λήψης
1. **Λήψη Φωτογραφίας** - Λήψη με ένα πάτημα
2. **Έλεγχος** - Επαλήθευση ποιότητας εικόνας
3. **Επιλογή Τύπου** - Επιλογή κατηγορίας αντικειμένου
4. **Προσθήκη Περιγραφής** - Προαιρετικές σημειώσεις
5. **Αυτόματο GPS** - Αυτόματη καταγραφή τοποθεσίας
6. **Αποθήκευση** - Αποθήκευση στη βάση δεδομένων

### Τύποι Αντικειμένων
| Τύπος | Εικονίδιο | Χρώμα |
|-------|----------|-------|
| Κεραμικά | Αμφορέας | Πορτοκαλί |
| Οστά | Οστό | Κρεμ |
| Μέταλλο | Ασπίδα | Γκρι |
| Πέτρα | Βουνό | Καφέ |
| Γυαλί | Ποτήρι Κρασιού | Κυανό |
| Οργανικά | Φύλλο | Πράσινο |
| Νόμισμα | Κύκλος | Χρυσό |
| Κόσμημα | Διαμάντι | Μοβ |
| Αρχιτεκτονική | Κτίριο | Μπλε |
| Άλλο | Ερωτηματικό | Γκρι |

### Χαρακτηριστικά
- **Λήψη με Ένα Πάτημα** - Ελάχιστη διεπαφή
- **Αυτόματο GPS** - Ενσωματωμένη τοποθεσία
- **Ταξινόμηση Τύπου** - Γρήγορη επιλογή κατηγορίας
- **Προαιρετική Περιγραφή** - Προσθήκη σημειώσεων αν χρειάζεται
- **Επιλογή Επανάληψης** - Εύκολη επανάληψη πριν την αποθήκευση
- **Ενσωμάτωση** - Σύνδεση με σύστημα πλήρους τεκμηρίωσης

## 14. Επικύρωση Δεδομένων

Αυτόματοι έλεγχοι ποιότητας δεδομένων που διασφαλίζουν την πληρότητα και την ακρίβεια της τεκμηρίωσης.

### Επίπεδα Επικύρωσης
| Επίπεδο | Εικονίδιο | Ενέργεια |
|---------|----------|---------|
| Σφάλμα | Κόκκινο X | Μπλοκάρει την αποθήκευση |
| Προειδοποίηση | Πορτοκαλί ! | Επιτρέπει αποθήκευση με ειδοποίηση |
| Πληροφορία | Μπλε i | Μόνο πρόταση |

### Επικύρωση Ευρήματος
**Υποχρεωτικά Πεδία (Σφάλματα):**
- Όνομα
- Τύπος

**Συνιστώμενα Πεδία (Προειδοποιήσεις):**
- Αριθμός πλαισίου
- Συντεταγμένες GPS
- Επισύναψη φωτογραφίας
- Περιγραφή
- Υλικό
- Ιστορική περίοδος

### Επικύρωση Φύλλου Πλαισίου
**Υποχρεωτικά Πεδία:**
- Αριθμός πλαισίου
- Τύπος πλαισίου

**Συνιστώμενα Πεδία:**
- Ερμηνεία
- Ανώτερο υψόμετρο
- Στρωματογραφικές σχέσεις

### Βαθμολογία Πληρότητας
| Βαθμολογία | Αξιολόγηση | Χρώμα |
|------------|------------|-------|
| 90-100% | Άριστη | Πράσινο |
| 70-89% | Καλή | Ανοιχτό Πράσινο |
| 50-69% | Μέτρια | Πορτοκαλί |
| 0-49% | Ελλιπής | Κόκκινο |

### Διάλογος Επικύρωσης
Κατά την αποθήκευση ελλιπών εγγραφών:
- Εμφανίζει ποσοστό πληρότητας
- Απαριθμεί όλα τα σφάλματα (πρέπει να διορθωθούν)
- Απαριθμεί όλες τις προειδοποιήσεις (συστάσεις)
- Επιλογές "Διόρθωση Ζητημάτων" ή "Αποθήκευση Ούτως ή Άλλως"
