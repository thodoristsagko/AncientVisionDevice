## Technical Deep Dive

### 1. Haar Discrete Wavelet Transform (DWT)

**Algorithm**: O(N) Cooley-Tukey-style pyramid decomposition
**Levels**: 3 (detail bands D1, D2, D3 + approximation A3)
**Applications**:
- **Denoising**: Soft thresholding via MAD (Median Absolute Deviation)
- **Transient detection**: Windowed energy with adaptive baseline
- **Frequency band energy**: Parseval's theorem conservation

**Example**: 256-sample vibration signal → D1 (50-100Hz), D2 (25-50Hz), D3 (12.5-25Hz)

### 2. Advanced Vibration Metrics

**Arias Intensity**:
```
Ia = (π / 2g) * ∫ a(t)² dt
```
Cumulative seismic energy, used in earthquake engineering for damage assessment.

**CAV (Cumulative Absolute Velocity)**:
```
CAV = ∫ |a(t)| dt
```
EPRI (Electric Power Research Institute) threshold: 0.16 g·s for equipment damage.

**Multi-Standard Classification**:
- **DIN 4150-3** (German heritage): 3 mm/s @ 1-10Hz, 8 mm/s @ 50-100Hz
- **BS 7385-2** (UK heritage): 6-15 mm/s interpolated
- **FHWA** (US): Flat 2.0 mm/s for ancient monuments
- **SN 640 312a** (Swiss): 3-8 mm/s interpolated

### 3. Variational Autoencoder (VAE)

**Architecture**:
```
Encoder:  10 → 8 → 6 → [z_mean=4, z_log_var=4]
Decoder:  4 → 6 → 8 → 10
```

**Reparameterization Trick**:
```
z = z_mean + exp(0.5 * z_log_var) * ε,  ε ~ N(0,1)
```

**Loss Function**:
```
L = MSE(x, x̂) * 10 + KL[q(z|x) || p(z)]
```

**Inference**: Deterministic (uses `z_mean` directly, no sampling noise)

**Advantages over Autoencoder**:
- Learns latent distribution, not just compression
- Better generalization to unseen anomalies
- Combined score (reconstruction + divergence) more robust

### 4. Bundle Adjustment (Levenberg-Marquardt)

**Optimization Target**: Minimize reprojection error
```
E = Σᵢ Σⱼ ||pᵢⱼ - K[Rᵢ|tᵢ]Pⱼ||²
```

**LM Update**:
```
(JᵀWJ + λI) δ = -JᵀWr
```

**Alternating Steps**:
1. Fix points, optimize camera poses (6 DOF: rvec + tvec)
2. Fix cameras, optimize 3D points (3 DOF per point)

**Robust Costs**: Huber / Cauchy / Tukey weight functions to handle outliers

### 5. CIDOC-CRM Metadata Export

**Standard**: ISO 21127 (Conceptual Reference Model for Cultural Heritage)

**Entity Classes Used**:
- **E22** Human-Made_Object (the artifact)
- **E7** Activity (excavation/finding event)
- **E53** Place (GPS coordinates)
- **E52** Time-Span (discovery date)
- **E55** Type (classification)
- **E57** Material (composition)
- **E3** Condition_State (preservation)
- **E12** Production (if known period)
- **E39** Actor (archaeologist)

**Output**: RDF/XML with URN-based identifiers
